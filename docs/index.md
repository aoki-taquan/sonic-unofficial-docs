## Sonic とは

Sonic は Rust で書かれた、軽量で高速な検索バックエンドです。Elasticsearch のような全文検索エンジンの軽量代替として設計されています。

- **軽量**: メモリ使用量が少ない
- **高速**: 検索クエリのレイテンシが極めて低い
- **シンプル**: スキーマ定義が不要
