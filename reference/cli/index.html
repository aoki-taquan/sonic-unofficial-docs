    aoki-taquan/sonic-unofficial-docs
    • SONiC 非公式ドキュメント
    • アーキテクチャ
      • ポート不正パケットドロップ設計（Interface MIB / L3 カウンタ拡張）
      • IP インタフェース ループバックアクション（同一 RIF 出戻りの drop/forward）
    • ルーティング
      • BGP router-id を明示的に設定する（DEVICE_METADATA.bgp_router_id）
      • linkmgrd のデフォルトルート連動（DualToR mux 制御）
      • ルータインタフェース (RIF) カウンタ
    • スイッチング
      • SYSTEM_DEFAULTS テーブルによる SONiC 既定値の集約
      • BUM ストームコントロール（PORT_STORM_CONTROL）
      • Wake-on-LAN（wol CLI と SonicWolService gNOI）
    • オーバーレイ
      • トンネルトラフィックの DSCP / TC リマップ（Dual-ToR PFC デッドロック回避）
      • NVGRE トンネル（nvgreorch / decap mapper）
    • ACL & QoS
      • DHCP DoS 緩和（ポート単位 DHCP レート制限・Linux TC ベース）
      • バッファ Watermark カウンタ（PG / queue 占有量の最大値追跡）
      • WRED / ECN 統計（per-queue / per-port、capability ベース）
    • システム
      • バナーメッセージ（login / motd / logout）
      • クリティカルリソースモニタリング (CRM) 要件
      • ログレベルの永続化（LOGLEVEL_DB → CONFIG_DB.LOGGER への移行）
      • 静的 DNS 設定（DNS_NAMESERVER と resolvconf 連携）
    • マネジメント
      • DHCPv4 Relay の giaddr を Primary サブネットに固定（VLAN_INTERFACE secondary）
      • gNMI Save-On-Set（Set ごとの ConfigDB 永続化）
      • シリアルコンソール全体設定（SERIAL_CONSOLE.POLICIES）
      • SSH サーバ全体設定（SSH_SERVER.POLICIES）
    • プラットフォーム
      • ICMP Hardware Offload（DualToR link prober の NPU 化）
      • SAI API バージョン整合チェック（sai_query_api_version + ビルド時検査）
      • SONiC Fast Link-Up（リンク再起動時の EQ 再利用）
    • 内部実装
      • VOQ カウンタ集約（chassis supervisor からの aggregate 表示）
      • バイト/パケットレートとポート使用率（RATES テーブル + EMA）
      • コンテナ health-check（k8s readiness probe）
      • ZMQ ProducerStateTable / ConsumerStateTable 設計
    • リファレンス
      • CLI
      • CONFIG_DB
      • YANG
